# Easy Access Bayan ng Montalban

Web app (PWA) and Android APK that give residents of Montalban (Rodriguez), Rizal
one place for hotlines, Municipal services and requirements, office hours and
locations, barangays, places to visit, and a "Report a problem" form, in
Filipino and English.

## Project layout

| Path | What it is |
| --- | --- |
| `www/` | The web app itself (plain HTML/CSS/JS, no build step). **Edit here.** |
| `www/data.js` | All content: hotlines, services, offices, barangays, places, announcements. |
| `android/` | Android project generated by [Capacitor](https://capacitorjs.com). It wraps `www/` into an APK. |
| `capacitor.config.json` | App ID (`ph.montalban.easyaccess`) and name. |
| `.github/workflows/android.yml` | Builds the APK on GitHub on every push to `main`. |

## Run the web app

```sh
npm install
npm start          # http://localhost:8000
```

### Online version

Every push to `main` that changes `www/` publishes the web app with GitHub Pages
at **https://bryz070925.github.io/easy-access-montalban/**. People can open it in
any browser and use "Add to Home Screen" to install it.

One-time setup: the repository must be public (or on a paid GitHub plan), and
**Settings → Pages → Build and deployment → Source** must be set to **GitHub Actions**.

## Get the APK

**On GitHub (no setup needed):** push to `main`, or open the **Actions** tab →
**Build Android APK** → **Run workflow**. When it finishes, download
`easy-access-montalban-apk` from the run's **Artifacts** section, unzip it, and
install `app-debug.apk` on an Android phone (allow "Install unknown apps").

**On your computer:** install [Android Studio](https://developer.android.com/studio)
(it brings the Android SDK) and JDK 21, then:

```sh
npm install
npm run apk:debug   # → android/app/build/outputs/apk/debug/app-debug.apk
# or: npm run sync && npm run open:android   (build/run from Android Studio)
```

After changing anything in `www/`, run `npm run sync` before building the APK
so the Android app gets the new files.

## App icon

Put the logo at `assets/logo.png` (square PNG, at least 1024×1024, transparent
background), then run:

```sh
npm install
npm run icons     # generates every Android icon and splash size
```

Commit the changed files under `android/`. For the web app, also replace
`www/icons/icon.svg` (or add a PNG and point `www/manifest.json` and
`www/index.html` at it).

## Before publishing to Google Play

The workflow builds a **debug** APK, which is fine for testing and sharing
directly. Google Play needs a **signed release** build (AAB): create a keystore,
keep it safe (losing it means you can't update the app), and configure signing
in `android/app/build.gradle`. Never commit the keystore; `.gitignore` already
excludes `*.jks` and `*.keystore`.
